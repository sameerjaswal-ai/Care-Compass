# Care Compass
CareCompass is a healthcare information and hospital discovery platform designed to help users find nearby hospitals and access essential healthcare information in one place. The project focuses on simplifying healthcare navigation by providing hospital details, available treatments, facilities, doctor information, treatment costs, and location-based services.  Key Features:  🏥 Hospital discovery based on location 📍 Location-based hospital information 💊 Treatment and estimated cost information 👨‍⚕️ Doctor details and specialties 🏨 Hospital facilities and services 🔐 User Sign Up / Sign In 🗺️ Interactive location-based interface 📱 User-friendly Streamlit interface  Tech Stack: Python, Streamlit, HTML/CSS, and location/map services.
